# 🎮 Web Games

Коллекция веб-игр в одном репозитории. Всё на чистом HTML/CSS/JavaScript: без фреймворков, сборки и зависимостей, в едином тёмном стиле с сестринским проектом [FinFocus](https://github.com/Folombas/FinFocus).

## 🕹 Игры

- **Крестики-нолики** (`index.html`): два режима (игрок против игрока и против ИИ), две сложности ИИ, автосохранение счёта и настроек, звуки, анимации, управление с клавиатуры (цифры 1-9).
  - Фишки — собственные SVG-ассеты: градиентный крестик и кольцо нолика со свечением, без внешних файлов.
  - ИИ уровня «Гроссмейстер» использует полный перебор минимаксом и непобедим: лучшее, чего можно добиться, это ничья.

## 🌐 Играть онлайн

Игра публикуется автоматически через GitHub Actions на GitHub Pages:

**https://folombas.github.io/web-games/**

## 🚀 Запуск локально

Сборка не нужна. Варианты:

- склонировать репозиторий: `git clone https://github.com/Folombas/web-games.git`,
- и открыть `index.html` в браузере (ES-модули требуют запуска через сервер, например `npx serve .`).

## 🧰 Стек

- Ванильные ES-модули (JavaScript), ноль зависимостей
- CSS Custom Properties, Grid, backdrop-filter, keyframes-анимации, `prefers-reduced-motion`
- Собственные SVG-фишки с градиентами и свечением (масштабируются без потерь)
- Web Audio API для коротких звуков без внешних файлов
- localStorage для счёта и настроек
- Минимакс с оценкой глубины для непобедимого ИИ
- GitHub Actions + GitHub Pages: автодеплой из `main`
